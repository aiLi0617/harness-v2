# 安全重构执行

> 确保重构过程中行为不变，每一步都可验证、可回滚，绝不夹带功能变更。

## 触发场景

- 执行 `refactoring-plan.md` 中的重构步骤时
- 任何涉及代码结构调整但不改变行为的场景

## 核心原则

1. **每步只做一种操作**：不在一次提交中混合"提取方法"和"重命名变量"
2. **每步后测试**：完成一步立即运行相关测试，确认行为未变
3. **红了回滚**：测试失败则立即撤销本步所有改动，回到上一个绿色状态
4. **禁止夹带**：重构过程中绝不夹带功能变更、bug 修复或优化

### 测试命令（与 test-guard 门禁一致）

| JaCoCo 状态 | 模块级 | 全量 |
|---|---|---|
| 已接入 check（`pom.xml` 含 `jacoco-maven-plugin` 的 `check` goal） | `mvn verify -pl <module> -am -q` | `mvn verify -q` |
| 未接入或仅 report | `mvn test -pl <module> -am -q` | `mvn test -q` |

已接入 JaCoCo check 时**禁止**仅用 `mvn test` 代替 `mvn verify`。

## 执行步骤

### 第一步：确认前置条件

在开始任何重构操作前：

1. 确认当前测试全绿（按上表选择 `mvn verify` 或 `mvn test`，Gradle 用 `gradle test`）
2. 确认 `refactoring-plan.md` 存在且有可执行的步骤
3. 确认目标代码所在模块的测试覆盖率足够支撑重构验证
4. 如果测试覆盖不足，**先补测试再重构**

### 第二步：逐步执行

按 `refactoring-plan.md` 中的步骤序号逐一执行：

```
对于计划中的每一步：
  1. 读取当前步骤的操作描述
  2. 执行单一重构操作
  3. 立即运行测试（模块级优先：mvn verify/test -pl <module> -am -q）
  4. 如果测试通过 → 标记完成，继续下一步
  5. 如果测试失败 → 立即回滚，分析原因：
     a. 操作本身有误 → 修正操作后重试
     b. 测试本身有问题 → 上报用户
     c. 连续两次失败 → 暂停，请求人工介入
```

### 第三步：单步操作规范

每种重构操作的标准执行方式：

**提取方法（Extract Method）**：
1. 选中目标代码块
2. 提取为新方法，保留原有参数传递
3. 原位置替换为方法调用
4. 运行测试

**搬移方法（Move Method）**：
1. 在目标类中创建方法副本
2. 调整参数（将原类作为参数或使用依赖注入）
3. 将原方法改为委托调用
4. 运行测试
5. 逐步将调用方切换到新位置
6. 运行测试
7. 删除原委托方法
8. 运行测试

**提取类（Extract Class）**：
1. 创建新类
2. 逐个搬移字段（每搬一个运行一次测试）
3. 逐个搬移方法（每搬一个运行一次测试）
4. 清理原类中的残留引用

**重命名（Rename）**：
1. 使用 IDE 重构功能全局替换
2. 检查字符串引用、反射调用、配置文件中的引用
3. 运行测试

### 第四步：验证完整性

所有步骤执行完毕后：

1. 运行全量测试（`mvn verify -q` 或 `mvn test -q`，按 JaCoCo 接入状态选择）
2. 对比重构前后的公共接口签名，确认无意外变更
3. 检查 diff，确认每行改动都可追溯到重构计划中的步骤
4. 如果发现计划外的改动，**立即撤销**

## 禁止事项

- **禁止**在重构提交中包含功能变更
- **禁止**在重构过程中"顺手"修复 bug
- **禁止**跳过测试执行
- **禁止**一次提交包含多种重构操作
- **禁止**修改测试用例的断言（除非重构了测试辅助方法的签名）

## 回滚策略

| 场景 | 操作 |
|------|------|
| 单步测试失败 | `git checkout -- .` 撤销当前步改动 |
| 多步后发现问题 | `git revert` 到最后一个绿色提交 |
| 重构完成后回归失败 | 按步骤序号逆序逐步 revert，定位引入问题的步骤 |

## 输出

每步执行后更新 `docs/artifacts/refactoring-plan.md` 中对应步骤的状态：

```markdown
| 序号 | 操作 | 状态 | 备注 |
|------|------|------|------|
| 1 | 提取方法 | ✅ 完成 | 测试全绿 |
| 2 | 搬移方法 | ❌ 回滚 | OrderValidator 缺少依赖注入，需先处理 |
| 3 | ... | ⏳ 待执行 | |
```
