# done-verify 使用说明

> 任何任务标记"完成"前强制执行的 8 关验证清单，是所有工作流收尾阶段的最后一道门禁。Agent 执行细节以 [`SKILL.md`](./SKILL.md) 为准。

## 这个 Skill 是做什么的

在 AI 准备声明"已完成"之前，按固定顺序逐关验证：编译、测试、Lint、变更范围、遗留项、制品完整性、安全、规则交叉引用。**快速失败**——前序关卡未通过不执行后续关卡。本技能负责编排"何时检查、按什么顺序检查"，具体标准由 feedback 层门禁规则定义。

- 由 workflow YAML 在收尾阶段强制调用，不依赖 AI 自觉
- 验证结果写入 `{artifact_root}/quality/verification-report.md`

## 适用场景

- 任务即将完成、准备声明"已完成"之前
- 各工作流的收尾阶段

## 验证关卡（顺序固定）

| 关 | 名称 | 失败处理 |
|----|------|----------|
| 1 | 编译检查 | 停止，回退 implementer |
| 2 | 测试检查 | 停止，回退 implementer |
| 3 | Lint / 静态分析 | 回退 implementer |
| 4 | 变更范围 | 回退无关改动或解释 |
| 5 | 遗留项（TODO/调试代码/注释代码） | 回退清理 |
| 6 | 制品完整性 | 补齐缺失制品 |
| 7 | 安全（密钥/敏感信息/注入） | **阻塞级**，回退修复 |
| 8 | 规则交叉引用（仅含 `.mdc` 变更时） | 移除跨文件引用 |

## 产出物

| 文件 | 说明 |
|------|------|
| `{artifact_root}/quality/verification-report.md` | 通过/未通过结论与失败项 |

## 关键约束

- 检查顺序固定，前序未通过不执行后续（快速失败）
- 安全检查为阻塞级别，不可跳过
- 每个关卡失败都生成一条 `harness-debug.md` 日志
